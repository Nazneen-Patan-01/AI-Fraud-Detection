# 💳 AI Credit Card Fraud Detection

## About the Project
A machine learning project that identifies potentially fraudulent credit card transactions using a Random Forest classifier.

## Features
- 🤖 Machine learning-based fraud prediction
- 📊 Interactive Streamlit dashboard
- 🔍 Transaction risk analysis
- 📈 Fraud probability display
- 💳 Sample transaction dataset

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## Live Demo
[Click here to try the app](https://ai-fraud-detection-j4zqimrrmkdwpqtyygtz6e.streamlit.app)

## Run Locally
1. Clone this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the app:
   `streamlit run app.py`

## Disclaimer
This is a portfolio demonstration using sample data. It is not connected to a real bank and should not be used for actual financial decisions.
